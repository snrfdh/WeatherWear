WeatherWear

Tentang WeatherWear

Cek Cuaca Kirim Masukan

WeatherWear adalah sebuah platform web inovatif yang merekomendasikan pakaian dan barang yang diperlukan secara otomatis berdasarkan prakiraan cuaca real-time di kota yang telah pengguna pilih.

Fitur Utama WeatherWear

  • 1. Pencarian cuaca berdasarkan lokasi yang diinput
  • 2. Perkiraan cuaca real-time
  • 3. Prediksi cuaca 7 hari ke depan
  • 4. Rekomendasi outfit & barang yang diperlukan

Sumber Data

Data cuaca dan lokasi diambil secara real-time dari Open-Meteo API yang merupakan layanan cuaca gratis dan terbuka.

Teknologi

  • 1. HTML5 untuk menentukan struktur dan konten halaman.
  • 2. CSS untuk mengatur tampilan, desain, dan keindahan.
  • 3. JavaScript untuk menambahkan fungsi, interaksi, dan logika.

Catatan
